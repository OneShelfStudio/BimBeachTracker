# BimBeachTracker 🇧🇧

**Live Coastal Telemetry, Sargassum Tracker & Real-Time Cameras across Barbados**

Public Web Application: [https://www.bimbeachtracker.com](https://www.bimbeachtracker.com)

## Overview
BimBeachTracker provides real-time oceanographic and coastal intelligence for all 46 beaches across Barbados:
- **44 Live Beach Cameras** with automated stale-feed detection.
- **Real-Time Marine Vectors:** Inshore wave heights, swell direction, period, and sea surface temperature via Open-Meteo.
- **Wind & Surface Groom Engine:** Real-time offshore vs. onshore wind analysis explaining glassy vs. choppy water.
- **Tidal Predictions:** High and low tide schedules synchronized to Bathsheba naval stations.
- **Intent & Vibe Filters:** Turtle Snorkel, Toddlers & Families, Surf Breaks, Sunset & Beach Bars, and Zero Sargassum.
- **Emergency Directory:** Tap-to-call direct numbers for Barbados Coast Guard, Police, Ambulance, and NCC Lifeguards.

## Tech Stack
- Next.js 14 App Router
- React 18 & TypeScript
- Tailwind CSS & Lucide Icons
- Open-Meteo Marine & Forecast APIs
- Deployed on Vercel with custom domain `bimbeachtracker.com`
